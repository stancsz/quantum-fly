# 开放协作边界

量子果蝇计划把可复现的研究核心开放给社区，用分布式实验验证研究假设。参与者自愿选择实验，比较基线和消融，并分享带有设置、随机种子、数据来源和资源记录的正面与负面结果。社区和维护者共同从证据中学习，而不是预先假定某个模型有效。

维护者的个人策略开发和交易由维护者单独安排和承担，不是社区实验的目标。社区时间和计算用于公开研究问题、可复现实验和结果交流。

## 计划公开的范围

- 模拟引擎、图和输入接口、评估工具，以及可复现的公开实验结果。
- 能够帮助他人复核方法和失败结果的配置、指标和文档。

## 可保持私有的范围

- 在许可允许的前提下使用的专有数据。
- 个人策略选择、参数、投资组合构造和执行系统。
- 不适合公开的账户信息、持仓、原始数据或商业部署细节。

参与者应在运行实验前看到预期资源使用。若成本未知，就明确标为未知。参与者自行选择实验和提交哪些结果，可以随时停止。结果应尽量附带配置、随机种子、数据 provenance 和资源指标，便于复核。

公开许可的贡献可能被维护者和其他社区成员用于商业用途，具体取决于项目届时选择的许可证。项目许可证尚未选择，本文件不构成许可证或权利转让。维护者不保证独占最强配置、盈利能力、报酬，或任何未明确授予的权利。社区获得可用工具、公开改进、共享结果和适当署名；贡献者不自动授予私有数据或私有结果的权利，也不存在对所有知识产权的笼统转让。

现有上游代码的 MIT 署名要求和 MaleCNS 数据的 CC-BY 义务继续有效。正式发布前仍需另行确定软件许可证、贡献条款和公开结果的具体许可方式。

这是计划中的研究协作边界，不是已经实现的权限、遥测、调度或上传机制。仓库目前也尚未公开发布。
