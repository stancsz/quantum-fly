# 多网络协作设计

这里的“蜂群协作”是多个决策网络之间的工程协作，不是共享意识，也不是已知的果蝇生物学专门化。当前首选 MVP 是三个彼此独立、有各自状态和学习历史的网络。它们可以共享同一份不可变解剖拓扑，但分别接收不同的市场特征视图：价格趋势、成交量和波动率。

```text
趋势特征 -> 网络 A ┐
成交量特征 -> 网络 B ├-> 固定均值或加权均值 -> 组合信号
波动率特征 -> 网络 C ┘
```

第一版先分别产生决策，再用简单的经典固定均值或预先定义的加权均值聚合。三个网络若使用完全相同的拓扑、状态和输入，并不能证明存在多样性。需要区分真正的网络多样性与抽样噪声，并保证输入按时间对齐且不泄漏未来信息。

本地 loop 已让网络交换有界的输出消息，并将成员状态与 step history 持久化；这只证明消息和重启 plumbing，不证明市场效果。相关错误、正反馈和同步协议问题仍需实验。直接加入跨网络神经元连接只作为探索性设计，因为耦合权重将是人为设定，不能声称有生物学证据。PennyLane 聚合器也只能作为后续实验：如果把三个信号映射到现有 4-qubit 架构，必须明确第四个输入的编码方式，不能把三个信号任意当成四个量子输入。

## 可证伪问题与对照

在匹配总计算预算下，三个独立网络是否比单一网络改善样本外决策质量或稳健性，仍是开放问题。零假设是没有具有实际意义的改善。至少比较：

- 单一网络接收全部特征；
- 计算预算匹配的单一网络；
- 相同拓扑和输入的三个完全相同副本；
- 使用不同特征视图并由经典聚合器组合的三个网络；
- 可选的量子聚合器；
- 在适用时使用随机打乱或度数匹配拓扑。

指标包括网络输出相关性和分歧度、扰动敏感度，以及在未来市场评估中加入交易成本后的质量、换手和回撤。动态状态应分别保存，不因共享不可变图而合并。三个完整网络能否适配目标资源必须通过 profiling 验证，不能预先承诺。

当前代码已经实现 synthetic fixture 上的多网络协作和真实 bounded connectome 的单网络接入；尚未证明多网络在真实连接组和市场评估上的优势，也尚未实现量子协调器。
