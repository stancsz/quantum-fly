# 研究假设

本文件把研究意图转成可证伪的假设。所有假设都需要预先定义指标、时间切分、随机种子和计算预算。若结果不支持假设，应保留负结果，不把它改写成成功叙事。

## 核心问题

在相同信息集、成本、训练预算和评估协议下，连接组启发的稀疏决策结构与经典计算机上的量子模拟，是否能改善投资组合决策的样本外稳定性，或改善风险调整后的表现？

## 可证伪假设

### H1：连接组结构的增量价值

相对于参数量、特征、训练预算和交易规则匹配的经典稀疏基线，使用雄性果蝇连接拓扑的模型在多个时间窗口的样本外稳定性指标上有可重复改善。

可证伪条件：若改善只出现在单一资产、单一窗口或单个随机种子，或在度数匹配拓扑中同样出现，则不能归因于该拓扑的特殊结构。

### H2：量子模拟步骤的增量价值

在固定输入和决策模型后，加入量子模拟的优化或稳定性评估，相对于同等计算预算的经典优化步骤，能在预注册指标上产生增量价值。

可证伪条件：若量子模拟没有超过经典对照，或收益完全由更多计算预算造成，则不支持该假设。

### H3：组合耦合价值

连接组启发结构与量子模拟结合后的模型，表现应超过两者各自单独使用的模型，并且优势在不同市场时期和多个随机种子下保持。

可证伪条件：组合模型不超过最佳单独模型，或优势无法通过消融实验定位到任何组件，则不支持该假设。

### H4：稳定性定义可测量

“量子稳定性”可以被拆成对市场扰动、参数噪声和抽样变化的敏感度，并形成可重复的指标集合。

可证伪条件：不同扰动协议给出互相矛盾的排序，或指标无法区分明显不稳定的决策，则需要重新定义术语，而不是继续使用当前定义。

### H5：多网络协作的增量价值

在相同总计算预算和时间切分下，三个分别接收价格趋势、成交量和波动率视图的独立网络，经简单经典聚合后，可能改善样本外决策质量或稳健性。

可证伪条件：组合不超过计算匹配的单网络、相同输入的重复网络，或优势只来自更多参数、更多抽样噪声或少数窗口，则不支持该假设。网络角色是工程设定，不是生物学专门化主张。

### H6：有限协调的增量价值

在匹配总计算预算下，拥有独立动态状态和低维 typed messages 的协调模块，可能比简单均值或加权均值改善样本外稳健性，但也可能因相关错误和反馈放大而变差。

可证伪条件：协调模块不超过简单聚合器，或其优势无法在多个时间窗口、种子和成本假设下复现，则停止升级协调结构。

## 零假设与必须报告的负结果

零假设是：在相同信息、成本、泄漏控制和计算预算下，各模型在样本外表现和稳定性上没有具有实际意义的差异。对多网络还要比较单网络接收全部特征、计算匹配单网络、相同拓扑和输入的重复网络、不同特征视图的经典聚合，以及可选量子聚合。还必须报告以下结果：连接组拓扑没有增量价值、量子步骤不如经典步骤、组合模型不如简单基线、多网络分歧只是抽样噪声、稳定性指标与收益无关、计算成本抵消了任何表现改善，以及结果对随机种子或窗口高度敏感。

## 不可从实验直接推出的结论

即使某个实验支持上述局部假设，也不能推出量子优势、生物学真实性、稳定可盈利交易、未来收益，或任何面向个人的投资建议。连接组解剖数据与可执行动力学之间的差距必须单独说明。
