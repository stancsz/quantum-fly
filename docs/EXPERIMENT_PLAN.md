# 实验计划

本计划用于把研究想法变成可复现的离线实验。它不是交易部署方案，也不是对硬件能力的承诺。

## 1. 明确表示与边界

先选择可管理的连接组子集或压缩表示，记录节点、边、方向、权重和拓扑处理规则。必须明确如何把市场特征编码为输入，如何更新节点状态，如何训练或优化参数，以及如何从模型读出资产权重。未经这些定义，解剖连接只能称为结构数据，不能称为已实现的神经网络动力学。

“量子稳定性”先按三类扰动记录：市场输入扰动、模型参数噪声、重采样或时间窗口变化。每类扰动都要有幅度、分布、重复次数和随机种子，并预先规定聚合指标，例如信号翻转率、权重距离、组合风险变化和结果区间宽度。

## 2. 对照组

至少实现以下条件，并尽量匹配特征、参数量、训练轮数和计算预算：

1. 经典密集或稀疏基线。
2. 连接组拓扑启发的模型，不使用量子模拟。
3. 量子模拟步骤，不使用连接组拓扑。
4. 连接组拓扑与量子模拟的组合模型。
5. 随机打乱拓扑和度数匹配拓扑对照。

多网络阶段还需比较 1 个策略模块、3 个独立模块、3 个模块加简单经典协调器，以及 3 个模块加独立状态的协调模块。协调器只接收低维 typed messages，风险约束保持在协调器之后。所有版本匹配总计算预算，并分别记录输出相关性、分歧、资源和失败率。

还应进行组件消融，例如移除方向、权重或特定拓扑约束，确认所谓优势不是来自参数规模或稀疏度本身。

## 3. 分阶段测试

### 多网络 MVP 设计

在进入真实数据前，使用三个独立状态的网络复用同一份不可变图结构，分别输入价格趋势、成交量和波动率。先分别读出信号，再使用固定均值或预先定义的加权均值。每个网络保留独立状态和学习历史，输入按同一时间点对齐。网络角色是工程化市场视图，不是已证实的生物学功能。

对照包括单一网络接收全部特征、计算预算匹配的单一网络、相同拓扑和输入的三个副本、不同特征视图的经典聚合，以及可选的量子聚合。量子聚合若使用现有 4-qubit 模块，必须明确定义三个信号到四个量子输入的映射，或把第四个输入留作待验证设计，不能任意补齐。输出相关性、分歧度、扰动敏感度和资源峰值都要记录。

### 阶段 A：最小可运行模型

使用合成市场特征和小型人工图，验证输入编码、状态更新、读出、扰动生成和指标计算。此阶段只能证明软件链路可运行，不能证明市场价值或生物学真实性。

### 阶段 B：拓扑与稳定性测试

在相同合成任务上比较真实拓扑、随机拓扑和度数匹配拓扑。改变参数噪声、输入扰动和采样方式，检查稳定性指标是否有区分能力，并记录运行时间、显存、内存和峰值资源。

### 阶段 C：历史数据离线评估

明确资产范围、特征生成截止时间、再平衡规则、交易成本、滑点和缺失数据处理。采用滚动或扩展窗口的 walk-forward 训练与样本外测试，禁止使用未来信息。所有模型使用相同时间切分和随机种子集合。

### 阶段 D：稳健性与复核

更换市场时期、资产集合、成本假设和随机种子。与简单基准比较，进行消融和度数匹配对照，并保存失败运行、超时和不收敛结果。只有在独立复核后，才讨论是否值得扩大数据或模型规模。

架构升级的顺序是固定递归 readout、三模块独立状态、因果奖励规则、协调器、最后才是可选量子聚合。不要把“queen fly”当成生物学结论，也不要在没有资源 profiling 前承诺三份完整网络可以运行。

多代理阶段的首个本地 JSON/event adapter、消息去重、超时、有界队列、证据引用和 pending cancel 已在 synthetic fixture 与 allowlisted Janelia 请求上验证。仍需补充真实连接组多成员运行、外部消息和 advisor；当前没有账户、凭据或 live action。

## 4. 评估协议

报告收益指标时同时报告波动、最大回撤、换手、交易成本后的结果和置信区间。报告稳定性时至少报告信号翻转率、权重距离、风险变化和对抽样变化的敏感度。不要只选择最好的窗口或种子。

计算比较必须包含相同的硬件或清楚记录硬件差异、墙钟时间、峰值显存、峰值内存、总运行次数和失败率。量子模拟若采用状态向量，应单独记录量子比特数、精度和内存估算，因为状态空间会随量子比特数指数增长。不能把经典机上的量子模拟等同于实际量子硬件执行。

## 5. 数据与资源计划

Janelia 下载页所列的完整片段连接图约 1.1 GB，突触位置约 12.7 GB，突触伙伴对约 6.8 GB，神经递质预测约 2.7 GB。这些表是可选的独立下载项。初期应优先选择能回答当前假设的最小数据表示，并记录下载版本、校验值、许可和预处理脚本。

实际资源需求依赖模拟器、状态表示、稀疏格式、精度、量子比特数和网络副本数，不能仅凭显存或系统内存给出最低硬件要求。用户报告可能使用 RTX 5070 Ti 16 GB 显存和 48 GB 内存，未来可用小规模阶段 A 和 B 做实测，但目前没有成功运行证据，也不应承诺三个完整网络、完整连接组或完整量子模拟一定适配该配置。

## 6. 复现与停止条件

每次运行保存代码版本、配置、数据版本、随机种子、时间切分、资源日志和结果摘要。停止条件包括：数据泄漏无法排除、对照组不公平、核心指标无法稳定定义、量子步骤只带来不可接受的计算成本，或结果仅依赖少数窗口与种子。任何停止都应作为研究结果记录。

当前本地 acceptance 命令为 `python -m scripts.run_local_research`。它运行官方数据子集、FRED 市场输入、稀疏状态更新和经典基线；安装可选 `pennylane` extra 时也记录 analytic 输出，否则 receipt 明确记录 quantum outputs unavailable。当前 receipt 记录 4,096 个注释 segment、扫描前 10,000,000 条权重行、160,053 条保留边、ID integrity、图输入扰动敏感度和 Python tracemalloc 峰值。这个边界是为了可复现运行，不代表完整图覆盖；扩大扫描前需要重新记录时间、峰值内存、边数和失败率。
