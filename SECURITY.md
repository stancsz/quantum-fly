# Security policy

Quantum Fly is an offline research prototype, not a supported production service. It does not place orders or require brokerage credentials.

For reproducible, non-sensitive defects, open a GitHub issue with the smallest safe example. Do not post secrets, private strategies, account information, unpublished datasets, or identifying personal data. If a report cannot be made safely without sensitive material, do not open a public issue. Contact the maintainer privately through their GitHub profile and include only enough information to arrange a safe disclosure channel.

Security fixes should preserve bounded inputs, explicit timeouts, allowlisted research access, and the separation between untrusted content and executable authority.
